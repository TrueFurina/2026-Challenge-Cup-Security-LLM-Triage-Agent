# 测试案例

> **版本**：v2.0（加入 LLM 实际输出对比 / 新事件类型说明）

本文档整理当前项目内置的主要演示 / 测试案例，以及每个案例预期展示的能力。

## 案例总览

当前内置 `10` 个核心事件：

- `EVENT-001` ~ `EVENT-010`

覆盖场景：高危脚本执行 / 运维误报 / 可疑外联 / 凭证导出 / 办公宏 / WebShell / 夜间登录 / 备份误报 / DNS信标 / 堡垒机枚举

## 1. EVENT-001 — 疑似 PowerShell 编码命令下载执行

**目标**：展示高危脚本执行事件的初步研判。

**关键特征**：PowerShell、EncodedCommand、可疑下载、恶意外联情报命中、历史高危相似告警。

**预期结果**：
- 事件类型：恶意脚本执行
- 风险等级：`critical`
- 误报判断：否

**LLM 实际输出（已验证）**：✅ `critical / 恶意脚本执行 / high confidence`

**适合展示**：情报查询、历史告警查询、高危事件风险升级。

## 2. EVENT-002 — 维护窗口内的运维脚本触发异常登录告警

**目标**：展示误报剔除能力。

**关键特征**：白名单、维护窗口、变更单、跳板机运维脚本、历史误报告警。

**预期结果**：
- 事件类型：异常登录（★ LLM 判为通用异常行为，更准——这是扫描非登录）
- 风险等级：`low`
- 误报判断：是

**LLM 实际输出（已验证）**：✅ `low / 误报=true`

**适合展示**：误报检查、资产重要性判断、历史误报继承。

## 3. EVENT-003 — 办公终端可疑外联但证据不足

**目标**：展示中风险、待确认事件场景。

**关键特征**：浏览器进程、低频域名访问、情报结论不明确、无进一步恶意下载。

**预期结果**：
- 事件类型：通用异常行为
- 风险等级：`medium`
- 误报判断：否

**LLM 实际输出**：`high / 异常外联`（★ LLM 发现 C2 域名特征，判定更高危）

**适合展示**：中风险保守定级、不夸大风险、输出继续观察建议。

## 4. EVENT-004 — 研发主机疑似凭证导出与横向移动前置行为

**目标**：展示凭证窃取与内部横向访问场景的高危研判。

**关键特征**：rundll32 异常调用、MiniDump/LSASS 痕迹、访问内部敏感文件服务器、历史同类高危事件。

**预期结果**：
- 事件类型：凭证窃取或横向移动前置行为
- 风险等级：`critical`
- 误报判断：否

**适合展示**：高危特征识别、横向前置研判。

## 5. EVENT-005 — 办公文档宏启动后触发异常外联

**目标**：展示办公宏投递和下载执行链识别。

**关键特征**：winword.exe 派生脚本宿主、外联低信誉下载域名、历史相似宏投递。

**预期结果**：
- 事件类型：可疑办公宏执行
- 风险等级：`high`
- 误报判断：否

**适合展示**：宏攻击链识别。

## 6. EVENT-006 — 核心数据库服务器疑似漏洞利用后写入 WebShell

**目标**：展示服务器高危入侵场景快速升级。

**关键特征**：服务进程处理异常请求、Web 根目录生成脚本文件、恶意回连情报命中。

**预期结果**：
- 事件类型：漏洞利用 / WebShell 落地
- 风险等级：`critical`
- 误报判断：否

**适合展示**：WebShell 检测、高危升级。

## 7. EVENT-007 — 人事终端夜间异常登录与可疑邮箱访问

**目标**：展示账号异常使用场景的上下文关联。

**关键特征**：夜间登录、大量附件访问、尝试外发。

**预期结果**：
- 事件类型：账号滥用或邮件异常使用
- 风险等级：`high`
- 误报判断：否

**适合展示**：账号行为分析、邮件滥用关联。

## 8. EVENT-008 — 备份服务器例行任务触发批量文件修改告警

**目标**：展示服务器侧批量行为的误报识别。

**关键特征**：备份窗口、白名单任务、变更单一致、历史误报告警。

**预期结果**：
- 事件类型：批量文件操作
- 风险等级：`low`
- 误报判断：是

**适合展示**：服务器侧误报识别。

## 9. EVENT-009 — 公网边界主机反复访问恶意域名并产生 DNS 信标

**目标**：展示典型 C2 回连场景识别。

**关键特征**：固定周期 DNS 解析、已知恶意域名、已知恶意 IP、历史信标告警。

**预期结果**：
- 事件类型：C2 信标回连
- 风险等级：`critical`
- 误报判断：否

**适合展示**：DNS 信标识别、C2 情报命中。

## 10. EVENT-010 — 运维堡垒机非常规时段执行账户枚举脚本

**目标**：展示越权运维和内部侦察场景分析。

**关键特征**：非维护窗口、账户枚举、远程共享查询、历史越权事件。

**预期结果**：
- 事件类型：内部侦察或越权运维
- 风险等级：`high`
- 误报判断：否

**适合展示**：越权运维侦察识别。

## 推荐测试方式

### CLI

```powershell
python -m security_agent.cli analyze --event-id EVENT-001
python -m security_agent.cli analyze --event-id EVENT-002
# ... EVENT-003 到 EVENT-010
```

### Web

```powershell
python -m security_agent.cli serve --port 8080
```

然后依次选择左侧事件进行验证。

### 全量评测

```powershell
python -m security_agent.cli evaluate
```
