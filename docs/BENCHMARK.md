# 业界基准与学术依据

> **用途**：为赛题论证提供业界基准和学术论文数据支持。
> **用法**：答辩引用"我们的评测方法对标业界标准"。

---

## 一、业界评测基准

### 1. CyberSOCEval（CrowdStrike + Meta）

**仓库**：[CrowdStrike/CyberSOCEval_data](https://github.com/CrowdStrike/CyberSOCEval_data)

**内容**：评估 LLM 在 SOC 任务的能力（恶意软件分析 + 威胁情报推理）。基于真实 CrowdStrike 报告 + Hybrid Analysis 数据。

**关键发现**：推理模型在安全领域优势不如代码/数学领域明显——说明安全领域需要专门设计。

**对本项目的意义**：论证"架构设计 > 追求最大模型"。

### 2. SecRespond（阿里巴巴 NLP）

**仓库**：[Alibaba-NLP/qqr](https://github.com/Alibaba-NLP/qqr)

**内容**：首个评估 LLM Agent 在"事后入侵响应"全流程的基准。10 个靶场、21 个 ATT&CK 技术、5 个操作系统、23 个前沿 LLM。

**关键发现**：无模型能在任意靶场完成 100% 检测 + 修复。

**对本项目的意义**：论证"agentic 安全是开放难题，有研究价值"。

### 3. ExCyTIn-Bench（微软）

**内容**：评估 LLM/Agent 在模拟 SOC 中做多步安全调查。8 个模拟攻击、57 张日志表、589 个 QA 对。

**关键发现**：最佳模型得分仅 0.368/1.0——留给安全 agent 的空间巨大。

**对本项目的意义**：论证"我们的 agentic 路线正确，且可贡献评测方法"。

### 4. DFIR-Metric（学术界）

**内容**：700 专家 MCQ + 150 CTF 取证 + 500 磁盘/内存取证案例，评估 14 个 LLM，引入 TUS 指标。

### 5. Awesome-AI-For-Security（汇总）

**仓库**：[AmanPriyanshu/Awesome-AI-For-Security](https://github.com/AmanPriyanshu/Awesome-AI-For-Security)

**内容**：AI 安全应用工具/论文/数据集大合集。

## 二、学术论文数据

### 1. AIDR（2025）— LLM 告警研判微调

**方法**：Qwen3-14B + LLaMA3-8B，LoRA 微调（rank 32, α=64），CoD 推理格式。

**数据**：

| 指标 | AIDR(微调) | CoT | 零样本 |
|------|-----------|-----|--------|
| 风险分级准确率 | **94.2%** | 90.1% | 67.2% |
| 威胁识别准确率 | 93.7% | — | — |
| 高危险召回 | 93.5% | — | — |

**结论**：微调提升巨大（比零样本 +27%）。

**对本项目**：论证微调小模型备选方案的可行性。

### 2. Elsevier SOC 论文（2025）— LLM 告警分类

**方法**：测试 8 个通用 LLM（OpenAI/DeepSeek/Ai2）+ 传统 ML，178 条人工标注告警。

**数据**：

- 二分类（真/假阳性）召回率 >90%（LLM 强）
- **多分类优先级（Low/Med/High/Crit）精度低、误报率高（LLM 弱）**
- 线性 SVM 达到最高整体 F1

**结论**：LLM 适合做初筛（二元分类），但精确分级需要混合架构/微调。

**对本项目**：直接论证"规则预筛 + LLM 深度研判"混合架构的合理性。

### 3. CyberSOCEval 论文（2025）

**结论**：大模型表现更好，但推理模型在安全领域提升不如代码领域。

### 4. pq-sift-defender（SANS FIND EVIL 黑客马拉松）

**数据**：Qwen2.5-1.5B 微调 → **96.3%** 准确率、100% BLOCK 检测、CPU 11s/条、986MB GGUF。

**对本项目**：微调小模型离线可跑，是 DeepSeek API 的可靠备选。

## 三、对本项目的应用建议

### 论证角度 1：混合架构合理性

> "业界论文表明：LLM 擅长二元误报分类（召回>90%），但精确分级精度不足（Elsevier 2025）。因此我们采用**规则预筛 + LLM 深度研判**的混合架构——规则先筛出明确误报，LLM 专注处理不确定事件。"

### 论证角度 2：agentic 安全是开放难题

> "微软 ExCyTIn-Bench 最佳模型得分仅 0.368/1.0，阿里巴巴 SecRespond 无模型能 100% 完成检测+修复。这证明 agentic 安全是开放前沿，我们的项目正是在这个方向上的工程实践。"

### 论证角度 3：架构 > 模型大小

> "CyberSOCEval 发现推理模型在安全领域优势不明显。因此我们不追求最大模型，而是通过工具调用链、知识检索、规则兜底构建**架构层面的智能**。"
