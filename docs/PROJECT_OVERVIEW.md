# 项目概述

> **版本**：v2.0（加入 AI 研判引擎）

## 项目主题

**基于 AI+安全大模型平台的安全事件初步研判与误报剔除智能体**

项目面向安全运营场景，不是通用聊天机器人。它关注的是：

- 安全事件发生后，如何快速做初步研判
- 告警或事件触发后，如何识别是否属于误报

## ★ 技术核心升级（本次）

从"硬编码规则研判"升级为"**AI 优先研判 + 规则兜底**"：

| 维度 | 旧版 | 新版 |
|------|------|------|
| 决策方式 | 15 个关键词硬编码计数 | LLM 综合证据推理 |
| LLM 角色 | 事后总结润色（装饰品） | **核心决策引擎** |
| 容错 | 规则引擎唯一 | LLM + 规则双通道（fail-open） |
| 富化 | 无 | MITRE ATT&CK / CVE / 调查步骤 |

## 项目目标

实现一个可运行的安全智能体原型：

- 接收安全事件或临时上传内容
- 查询资产、日志、情报、历史告警和知识库
- **LLM 综合证据推理**，生成事件类型、风险等级、风险评分和误报判断
- **规则引擎兜底**，LLM 不可用时不崩溃
- 输出结构化结果和处置建议
- 导出研判报告

## 当前定位

当前代码适合作为：

- 比赛原型（挑战杯 XH-202614 / XH-202609）
- 课程 / 论文展示项目
- 安全智能体工作流示例

已具备完整演示链路，还不是生产级安全平台。

## 适用场景

- PowerShell 脚本执行类异常
- 可疑外联类事件
- 运维维护窗口触发的疑似误报
- 需要结合资产、日志、情报和历史记录进行快速初判的安全事件

## 当前输出内容

- 事件类型
- 风险等级
- **风险评分（0-100）**
- 置信度
- 是否疑似误报
- 计划步骤
- 推理摘要
- 证据链
- 工具观测
- 处置建议
- 结构化 JSON
- Markdown / JSON 报告
- **AI 富化（ATT&CK / CVE / 调查步骤）**
