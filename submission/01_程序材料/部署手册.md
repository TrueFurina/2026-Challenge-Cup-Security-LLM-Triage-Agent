# 部署手册（XH-202609 程序材料）

> 对应命题书要求：程序材料 = 源代码 + **一键部署方案 / 完整部署手册** + 在线可测试访问地址（二选一）。
> 本作品交付「本地一键起 + 容器部署手册」两种路径，满足命题书要求。

---

## 1. 环境要求

| 项 | 要求 |
|----|------|
| 操作系统 | Windows / Linux / macOS |
| Python | **3.13+**（代码 `requires-python>=3.13`，已在本机 3.13 验证）|
| 运行时依赖 | **无强制依赖**；真实 LLM 模式需 `httpx`（可选）|
| 大模型 API | 可选。国内备案模型（默认 DeepSeek）。无 Key 时自动回退规则引擎，全功能可演示 |

> **工程亮点（对应评分「系统架构与工程实现」）**：零重依赖、fail-open 设计——任何异常都安全降级，绝不崩溃。

## 2. 路径 A：本地一键起（推荐，最便捷）

```bash
cd "E:\Program\2026挑战杯：Security-Agent-安全事件研判智能体"

# ① 验证环境（无需 API Key）
python scripts/_verify_syntax.py      # 语法检查
python scripts/_prefilter_test.py     # 预筛器测试 25/25

# ② 一键启动 Web 大屏
python -m security_agent.cli serve --port 8080
# 浏览器打开 http://127.0.0.1:8080
```

启动后可用功能：
- 首页：大屏指标卡 + AI 决策可视化
- `/generate-modes`：三模式对比柱状图（纯规则 / 纯 LLM / 混合）
- `/ledger`：审计回放（全证据链时间线）
- 事件详情：risk_score 数值条 + 置信度徽章 + 研判路径

真实 LLM 模式（可选）：
```bash
set DEEPSEEK_API_KEY=你的密钥      # Windows
python -m security_agent.cli serve --port 8080
```

## 3. 路径 B：容器化部署（可复现、便于评审环境）

```bash
cd "E:\Program\2026挑战杯：Security-Agent-安全事件研判智能体"

# 一键构建 + 启动（脚本自动绑定 0.0.0.0）

# 或手动：
docker build -t security-agent-xh202609:latest .
docker run -d -p 8080:8080 -e DEEPSEEK_API_KEY=安全-agent-xh202609:latest
docker run -d -p 8080:8080 -e DEEPSEEK_API_KEY=xxx security-agent-xh202609:latest
```

镜像说明：基于 `python:3.13-slim`，仅安装 `httpx`（真实 LLM 用），**不安装 pyproject 中遗留的 langchain/openai**（代码未引用，安装即浪费且可能装崩）。

## 6. 常见问题

| 现象 | 原因 | 处理 |
|------|------|------|
| 启动报缺少 httpx | 未装可选依赖 | `pip install httpx` |
| 页面打不开 | 默认绑定 127.0.0.1 | 容器加 `--host 0.0.0.0`；本机访问用 127.0.0.1 |
| LLM 无响应 | 未配置 Key 或网络受限 | 属预期，自动回退规则引擎，功能不受影响 |
| Python 版本报错 | 用了 <3.13 | 升级到 3.13+ |
