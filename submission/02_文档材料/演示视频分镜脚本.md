> 工具：OBS /  PowerPoint 录制 / 系统 Xbox 录屏（Win+G）。建议 1080p、旁白 + 鼠标高亮。

**镜 2（0:30–1:15）三大痛点**

## 第二幕：架构与核心能力（2:00–5:30）

**镜 4（2:00–2:45）六层架构**
- 画面：PPT 第 4 页 + `docs/ARCHITECTURE.md` 架构图
- 旁白：输入→预筛→LLM 深判→多 Agent→闭环处置→审计账本，六层自主决策闭环。

**镜 5（2:45–3:30）确定性预筛（实测）**
- 画面：终端跑 `python -m security_agent.cli analyze --event-id EVENT-001`，展示 0.2ms 定级；再 EVENT-002 误报 0.1ms 关闭
- 旁白：预筛三态分流，LLM 调用节省 70%——这是自主初判。

**镜 6（3:30–4:15）置信度门控 + HITL**
- 画面：PPT 第 6 页 + Web 事件详情「待人工复核」徽章 + 复核按钮
- 旁白：低置信不自动处置，人工复核回写，形成负责任的自主任闭环。

**镜 7（4:15–5:00）多 Agent + 知识库**
- 画面：终端 `python -m security_agent.cli coordinate --event-id EVENT-001` 展示 Triage→Hunt→Respond→Report 全链路
- 旁白：四 Agent 顺序协作，前序驱动后序；RAG 知识库注入 ATT&CK/CVE 依据降幻觉。

**镜 8（5:00–5:30）审计账本**
- 画面：Web `/ledger` 审计回放页，时间线展开某事件证据链
- 旁白：每次研判的 prompt、LLM 响应、工具调用全记录——决策可回放、可审计、可导出。
