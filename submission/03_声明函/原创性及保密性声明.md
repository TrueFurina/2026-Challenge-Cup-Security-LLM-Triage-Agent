本人（团队）声明所提交的参赛作品 **《【作品名称：基于 LLM 与确定性规则混合架构的安全事件研判智能体】》**（对应赛题编号 **XH-202609**）及所有相关材料，均为参赛团队在指导教师指导下**独立构思、自主完成**的成果。

## 二、保密性声明

本作品在研发与提交过程中，可能涉及以下保密事项：

1. 参赛团队在研发中使用的内部测试数据、日志样本，均已做脱敏处理，不包含任何真实生产环境的敏感信息；
2. 作品涉及的模型 API 调用、部署环境信息等，仅在赛事评审与受控测试环境内使用，不会对外泄露；
3. 参赛团队承诺：在赛事期间及赛后，不将发榜单位（杭州安恒信息技术股份有限公司）提供的未公开技术资料、测试平台信息用于任何商业或第三方用途；
4. 作品若包含第三方开源组件，均已遵守相应开源协议；商业闭源组件均已获得合法授权。

本人（团队）理解并同意：赛事组委会及发榜单位有权在评审、宣传、成果转化等范围内合理使用本作品材料。
